# v1.8 随机 class 也按元素画框：highlight 支持 text=

> 2026-10-29

`shot --highlight` 原来只认 CSS 选择器。class 是随机哈希的页面（控制台类 SPA，伙伴云表格行内的按钮如 `_buttonItem_sD72zb`）写不出稳定的选择器，只能退到 annotate.py：先 `--grid` 出网格图、从图上读百分比、再画框，多一轮截图和读图。

本版让 `--highlight` 按界面文字找元素，读网格只留给目标不在页面结构里的情况。

## 摘要

1. 新增: `--highlight` 支持 `text=界面原文`，命中文字完全相等的最外层可见元素（按钮本身，不是里面的 span），可与 CSS 选择器混用，多个仍用 `,,` 分隔、按传入顺序标序号
2. 新增: 同一文字有多处时写 `text=原文|序号`，按屏幕位置从上到下、从左到右数；命中多处且没写序号时 shot 提醒
3. 变更: annotate.py 的适用范围收窄为两种：目标不是页面元素（canvas 图表、跨域 iframe、图片里的内容），以及 `--blur` 的选择器写不出来时打码；walkthrough-guide 第五节、SKILL.md 依赖表、annotate.py 头注释同步
4. 新增: selftest 用无头浏览器补三条用例

## 验证

| 用例 | 预期 | 结果 |
|---|---|---|
| `text=筛选`：按钮外层 div 内套 span，另有一个隐藏的同名元素 | 只命中外层 div | 通过 |
| `text=发货`：三个同名按钮在 DOM 里乱序 | 按屏幕从上到下排 | 通过 |
| `text=发货\|2` 与 `text=筛选` 一起传 | 取屏幕上第 2 个，按传入顺序 | 通过 |
| 伙伴云进销存 v5.0 订单表（真实页面，Chrome 内执行同一段命中逻辑） | 「筛选」「1 排序」命中工具条按钮；「发货」命中行内按钮而非内部文字；「泛海国际」命中所在单元格 | 符合 |
| selftest 全量 | 无回归 | 28 项通过 |

## 已知未覆盖

- 只认完全相等的文字。按钮文字里带变化的数字（如「1 排序」随排序条数变）要按当时的界面原文写。
- 文字相同、位置也相邻的元素（如标签和同名单元格）会都命中，靠 shot 回显的「框中元素」和读回复核。
- browser.py 完整走查链路（start → shot）未在本版重跑，`text=` 只在页面内逻辑和 selftest 层验证。
