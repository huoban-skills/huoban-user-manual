# huoban-user-manual

伙伴云图文手册生成 Skill：用浏览器实际操作伙伴云系统，边走查边截图，产出带真实截图的图文手册（Markdown + 图片目录 + HTML 预览）。

给 Claude Code 用。装好后对着一个搭好的伙伴云工作区说"给这个工作区出一份使用手册"，剩下的事它自己干：拉配置、开浏览器实测、截图标注、成稿、自检。

## 两种产物，一次一本

| | 使用手册 | 配置手册 |
|---|---|---|
| 给谁看 | 业务操作者（一线员工） | 系统管理员、接手的实施同事 |
| 回答什么 | 我该做什么、系统会给我什么 | 配置在哪、为什么这么配、改了影响什么 |
| 结构 | 成册模块手册，一章一个业务动作，册末带典型业务场景串联 | 第一章成果展示，之后按搭建顺序分章（建表 → 自动化 → 审批流 → 权限 → 页面） |
| 深度 | 照着能操作 | 看懂 + 敢小改，重点写改动影响 |

## 核心特点

- **双轨采集**：hac CLI 管逻辑真相（字段、自动化、审批流），Playwright 浏览器管界面真相（截图、交互、提示文案），冲突以实测为准。
- **真实截图，不是示意图**：所有配图来自浏览器实际走查，导航高亮、按钮位置和步骤文字逐张核对一致。
- **标注有章法**：柔和描边样式（珊瑚色圆角框 + 白边 + 投影），多框自动标 ①②③ 序号，含义写在步骤文字里；非必要不画框。
- **脱敏内置**：演示数据不打码，只对混入的真实客户信息做模糊；选区不遮字段名和系统文字，交付前两遍复检。
- **业务流程图**：册头一张全流程图（脚本渲染 SVG），步骤标落表、系统自动环节置灰，不手画。
- **格式机检**：渲染时自动校验章序号、小节编号、图号图注、步骤序号和图片死链，有问题报行号、退出码非零。
- **省 token**：配置数据批量落盘不进上下文，按章取摘要包；一章写完不把细节带进下一章。

## 安装

```bash
git clone https://github.com/huoban-skills/huoban-user-manual.git ~/.claude/skills/huoban-user-manual
```

依赖：

- hac（伙伴云官方 CLI，已配置认证）
- python3 + Playwright（chromium）：`pip install playwright && playwright install chromium`
- Pillow（截图标注用）：`pip install pillow`

## 使用

在 Claude Code 里直接说：

- "给 XX 工作区出一份使用手册"（或"操作手册""带截图的实测手册"）
- "给 XX 工作区出一份配置手册"（或"搭建手册""交付配置文档"）

流程分四个阶段，两处需要你确认：

1. **需求对齐 + 定骨架**：确认写哪本、范围、演示环境，骨架（章节清单）确认后才动手。
2. **轻采集**：配置数据批量落盘，摘要要点给你过目。
3. **逐章循环**：深查配置 → 浏览器走查截图 → 写稿 → 渲染预览。
4. **自检 + 交付**：对照自检清单逐项过，交你审阅。

首次使用会弹出浏览器窗口让你登录伙伴云（账号密码自己输，登录态持久化，之后免登录）。

## 产出结构

```
<模块名>/
├── <模块名>.md            # 使用手册源文件（配置手册则为 <模块名>-配置手册.md）
├── <模块名>.html          # 预览，render.py 从 md 渲染
├── images/                # 截图与流程图
├── outline.md             # 骨架清单（表、页面、章节）
├── notes.md               # 实测笔记（交付时可删）
└── demo-data.md           # 演示数据登记（清理完可删）
```
